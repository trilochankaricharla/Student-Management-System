# Student Management System

A desktop-based Student Management System developed using Python, Tkinter, and SQLite.

## 📌 About the Project

This project is designed to manage student information through a simple graphical user interface. It was developed as a practical project to strengthen Python programming, GUI development, and database management concepts.

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite

## ✨ Key Features

- Add student information
- Search student information
- Delete student information
- Store student data using SQLite
- Simple graphical user interface

## 📂 Project Structure

- `dashboard.py` - Main dashboard/interface
- `add_student.py` - Add student functionality
- `search_student.py` - Search student functionality
- `delete_student.py` - Delete student functionality
- `database.py` - Database-related operations

## ▶️ How to Run

1. Install Python 3.x.
2. Clone this repository.
3. Open the project folder.
